Tech stack:

Language: Python 3.10 or 3.11
Data: pandas, scikit-learn, NumPy
ML: PyTorch
FL: Flower (flwr)
DP: Opacus
Secure Aggregation and attacks: NumPy
Plots: matplotlib
Backend: FastAPI + Uvicorn
Frontend: React (Vite) + Recharts
Storage: CSV/JSON files only, no database
Environment: requirements.txt with pinned versions. Flower and Opacus change APIs between releases, so everyone must install the same versions.
