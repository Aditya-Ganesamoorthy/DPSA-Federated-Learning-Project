# Demo script (about 3 minutes)

**Before the demo:** open the deployed app https://fl-lung-cancer.onrender.com (wake it up a minute early; the free instance sleeps), or run locally (`python -m uvicorn backend.main:app --port 8000` after `npm run build`). Have two CSV files ready (for example `data/clients/noniid_hospital_1.csv` and `noniid_hospital_2.csv`) and two browser windows (one normal, one private) so you can act as two hospitals.

1. **Overview: Security & Privacy Analysis Dashboard (40 s).** "Every training round is audited. Registered hospitals, how many reported this round, updates received, accepted and rejected. The big **NO**: raw patient data never leaves a hospital: 0 rows, only 1,057 weights and a row count. Privacy status shows whether differential privacy was used, the largest epsilon, and below it the detected attacks, the security events and a transparent risk score per round."
2. **Ordinary vs protected demo (30 s).** Scroll to the demo and press *Run a new session*. "Same hospitals, same attacker. In ordinary federated learning the poisoned update is accepted and drags the model; in the protected session the size guard rejects the blatant one and median aggregation neutralises the stealthy one. Membership-inference leakage and epsilon are measured results; the risk score drops from 85 to 25."
3. **EDA (15 s).** Scroll to the data analysis: balanced classes, nearly identical age profile, correlations all near zero (|r| ≤ 0.04). "This is why every model sits near chance: the project demonstrates the privacy-preserving process, not a diagnostic tool."
4. **Register two hospitals (30 s).** In window 1 click *Register hospital*: name, parent network (for a sub-hospital), username, password. No administrator is involved. Do the same in window 2.
5. **Train & Contribute, hospital 1 (40 s).** Open *Train and Contribute*, drop in the first CSV. The file is read in the browser and shows rows and cancer rate. Press *Train and contribute*. Point at the animation: the model is downloaded, a ring fills while the hospital trains ("patient data stays local"), only weights travel upward, and the server shows "1 of 2 hospitals reported".
6. **Hospital 2 with differential privacy (40 s).** In window 2, load the second CSV, switch on **Differential privacy**, point at the epsilon preview, and train. The round closes: the server animates the FedAvg step and the Hugging Face update, and window 1 completes by itself ("New global model v1").
7. **Live Federation (20 s).** Show the network table (both hospitals, the sub-hospital relationship, epsilon of the DP hospital), the version history with the risk badge, and open the Hugging Face repo to show v1 published.
8. **Back to Overview (10 s).** The dashboard now shows 2 hospitals, 2 updates accepted, privacy status *partial* and the round's risk breakdown.

**Limitations to state (10 s):** near-random dataset, secure aggregation is only simulated (the live server sees each hospital's update), DP is client-declared, open registration means poisoning is limited by the size guard and median aggregation (set an invite code to restrict joining), and the free Render tier sleeps.

**If the server is unreachable or asleep:** a red banner with Retry appears; wait about a minute for Render to wake (or restart uvicorn locally).
**Solo demo:** with `MIN_CLIENTS=1` a single hospital can close a round alone (set it in Render's Environment tab).
